# What Stays — standalone Cloudflare Pages package

Download `What-Stays-Cloudflare.zip`, then use Cloudflare Workers & Pages → Create application → Pages → Upload assets (Direct Upload). The archive root contains index.html. The package is prepared, not yet deployed to Cloudflare.

English is the default; Chinese uses ?lang=zh. The section menu links back to the personal website. Existing music credits and license records are preserved.
