## 图文与交互

- 主界面按原始比例完整展示，不设置固定高度裁切。桌面并列对照，手机选择切换；补充界面展开后同样完整展示。
- 全部素材来自用户已上传文件，不生成新角色。首屏与亲子照片保留去水印版本。
- 原有成长目标原型只截图复用，不另画新风格。`goal-settings.webp` 为旧原型的设置界面，`goal-added.webp` 为旧补画的添加后目标界面。
- 同页六步路径：成长中心 → 动画内容 → 动画详情 → 播放动画 → 设置成长目标 → 查看目标。节点之间连续箭头，之后连接智能玩偶提醒 → 孩子实际行动 → 家长确认。
- 原动画在第四步播放，不自动播放，离开动画步骤即暂停。目标两步持续标记方案示意，不当作历史上线交付。
- 所有界面及照片可以放大；长图在弹窗中滚动。原录屏不入页面。
